# حول سن الحضانة والرعاية المشتركة بالمناصفة — النصوص والمصادر

مستودع البيانات والدستور وأدوات البناء (الإصدار 1.29.0: 466 بطاقة في 22 قسما، و8 بطاقات للمراجعة، ومعها البطاقات المختصرة بنمطيها وجدول النشر).

## المحتويات
- `data/` — ملف البيانات `nuqul_7_9.json` ومخططه، والتصدير النصي، والدستور، ومنزلة المصادر، والملف الميسر، ومدخلات البناء (`new_cards.json` وغيرها).
- `base/` — الطبعة الأساس التي تبنى عليها البطاقات.
- `verify/` — نتائج مطابقة المصادر وفحص الروابط، وملف التصحيحات `overlay.json`.
- `tools/` — الخمسون الأقوى، مذكرة المناظرة، المذكرة التشريعية، تعليقات فيسبوك وجدول النشر، نصوص الفيديو، الطبعة الإنجليزية.
- `scripts/` — سكربتات البناء.

## إعادة البناء بأمر واحد
1. ثبت المتطلبات مرة واحدة:

```
pip install playwright segno jsonschema && python -m playwright install chromium
```

2. شغل:

```
./build.sh
```

3. تجد المنتجات كلها (HTML وPDF بطبعتيه، وصور الأقسام، وطبعة فيسبوك، والبيانات) في المجلد:

```
_work/build
```
